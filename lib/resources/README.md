# Resources

This directory contains:

- `how-it-works-html.ts` — self-contained HTML for the "How Makuri works" interactive MCP Apps widget (`ui://makuri/how-it-works`).
- `romanian-quiz-html.ts` — self-contained HTML for the Romanian mini-quiz widget (`ui://makuri/romanian-quiz`).
- `docs.ts` + `register-docs.ts` — markdown documents exposed via MCP `resources/list` / `resources/read` (`makuri://docs/manifesto`, `makuri://docs/safety-overview`, `makuri://docs/connect-guide`).

All content is static, self-contained, and free of user data, API keys, and network calls.
